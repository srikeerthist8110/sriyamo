# SRIYAMO

SRIYAMO clothing storefront — a modern everyday-kurti ecommerce homepage.

## Included
- Promotional announcement bar and 70% OFF campaign area
- New arrivals and best sellers
- Wishlist interactions
- Shopping cart
- Search modal
- 1+1 offer promotion area
- UPI and COD payment messaging (50% advance + 50% on delivery for COD)
- Responsive mobile layout
- SRIYAMO story/about section

## Run
Open `index.html` in a browser, or deploy the repository with GitHub Pages.
